# Hướng dẫn khai báo mã hàng

Admin tạo mã hàng bằng popup trên danh sách hoặc tải file mẫu để nhập nhiều mã hàng. Mỗi mã gồm mã, tên và cycle time tính bằng giây. Cycle time phải lớn hơn 0.

Nhập Excel sẽ kiểm tra trùng mã, dữ liệu bắt buộc và định dạng trước khi ghi. Nếu có lỗi ở bất kỳ dòng nào, toàn bộ file bị chặn để sửa rồi tải lại; hệ thống không nhập một phần. Giới hạn file 10 MB và 5.000 dòng; bản xem trước hết hạn sau 15 phút.

Mã hàng chỉ lưu mã, tên và cycle time. Công đoạn được khai báo tại PO.
